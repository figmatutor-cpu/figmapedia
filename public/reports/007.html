- 도메인 주도 설계(DDD) : 코드나 기술보다 서비스·비즈니스 원칙과 유저 스토리를 먼저 정의한 뒤 설계하는 방식
- 서비스 도메인 : 서비스 사용자가 어떻게 작업하고 행동하는지 인터뷰로 구체적으로 뽑아낸 내용
- 작업 도메인 : 내가 실제로 일하는 프로세스(예: 레퍼런스 → 화면 설계 → 피그마 와이어프레임)를 인터뷰로 뽑아낸 내용
- 도메인 스토리텔링 인터뷰 : 위 두 도메인을 끌어내기 위해 AI와 진행하는 인터뷰 방식
