- MCP 개념 : LLM 도구와 다른 서비스를 연결하는 표준으로, AI가 외부 데이터를 읽고 쓰고 작업하도록 "손과 발"을 달아준다.
- 커넥터·플러그인 : Claude나 GPT의 커넥터와 플러그인도 결국 플랫폼이 MCP를 쉽게 연결하도록 설정해 둔 것이다.
- 워크플로우 조합 : MCP를 하나만 쓰기보다 여러 개를 묶어 쓰는 것을 권하며, 예로 Figma·Playwright·Talk to Figma MCP를 묶은 디자인 QA 에이전트와 Figma·Whimsical MCP를 묶은 와이어프레임 생성 에이전트를 든다.
- 직접 제작 : 목적과 요구사항, 지켜야 할 점(예: 폰트 저작권 확인, 억지 다운로드 금지)을 쪼개 전달하면 AI가 서버까지 구축
